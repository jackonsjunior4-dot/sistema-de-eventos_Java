# sistema-de-eventos_Java
Nosso objetivo é desenvolver, em Java e em console, um sistema que ajude moradores de Porto Alegre a descobrir e acompanhar eventos da cidade, como shows, feiras gastronômicas, jogos e palestras. O usuário se cadastra com nome, e-mail, idade e bairro, consulta a agenda de eventos, confirma presença e pode cancelar depois
